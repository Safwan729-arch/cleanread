## 2026-09-11

Greenfield start — repo held only `CLAUDE.md` and an empty default Obsidian vault.

**Scaffold**
- Moved the Obsidian vault root to the repo root so `/notes/` sits inside it — see [[vault-at-repo-root]]
- Vite 8 + CRXJS 2.7.1, React 19, dual `dist/chrome` + `dist/firefox` output — see [[build-pipeline]]
- Hit a real CRXJS trap converting the MV3 background for Firefox — preserved in [[firefox-deferred]]
- Built the core flow: extraction, distraction removal, reader overlay, font/spacing/dark mode, reading time — see [[reader-view]]
- Dexie schema + helpers written and building, but no UI calls them yet — see [[storage-layers]]

**Then actually ran it in Chrome, which was the valuable part** — see [[running-the-extension]]
- Getting an extension loaded at all took four separate fixes; `--load-extension` is gone
  in Chrome 137+, and Playwright's default `--disable-extensions` hides the failure
- The first screenshot exposed two bugs the build could never have caught:
  1. Ad blocks *inside* the article survived Readability into the reader view →
     added a `scrubJunk()` pass, details in [[reader-view]]
  2. Host page CSS (`article { background:#fff }`) bled into our overlay →
     moved the whole view into a shadow root, see [[shadow-dom-isolation]]
- Kept the driver as `npm run smoke:chrome` so this isn't re-derived

Verified: `npm run build` green for both targets; both manifests correct;
`npm run smoke:chrome` passing against the fixture *and* a live Wikipedia article.
**Firefox is build-verified only** — Firefox is not installed on this machine.

Added extension icons — generated, not hand-drawn — see [[extension-icons]]. Smoke test now
30/30 and asserts every icon size actually loads.

**Scope change, same day:** dropped Firefox — Chrome only from here. Dual-target build,
`cross-env` and the manifest transform are gone; output moved `dist/chrome` → `dist/`.
Source code was not touched: `browser.*` / webextension-polyfill stay, so the port remains
a build-config change. Rationale and the full restore recipe: [[firefox-deferred]].

Built the table of contents — see [[table-of-contents]]. Running it found two bugs that no
build could: the last sections were unreachable by the scroll spy, and the active marker
went stale after a font-size reflow. Smoke test now 44 checks.

Built paragraph highlighting — see [[paragraph-highlighting]]. It uncovered a build bug that
had been live the whole time: both entries were named `index.js`, so the service worker was
running the *content script* bundle and the real background had never executed — see
[[entry-filenames-must-differ]]. Also fixed highlights being orphaned by a `#fragment`.
Smoke test now 50 checks.

Built save-article — reading list in the popup plus an offline saved-article page that
reuses the reader stylesheet — see [[save-article]]. Smoke test now 63 checks, including a
real popup-driven save (the popup is opened as a background tab so it sees the article tab
as active, the way a toolbar click does).

Built Markdown export — see [[markdown-export]]. Reading the exported file end to end
exposed a bug that had been in the reader view all along, below the fold: the cookie banner
survived extraction, because Readability unwraps such blocks into class-less `<p>` tags.
Scrubbing now also matches the text of `fixed`/`sticky` elements read off the live page —
see [[distraction-removal]]. Smoke test now 77 checks.

Built PDF export — see [[pdf-export]]. The first working version clipped the right edge of
every line: parked off-screen at a negative offset, html2canvas measures against the window
rather than the render column. Fixed, with a guard asserting the embedded image width.
The ~900KB library is dynamically imported so it only loads on use. Smoke test now 84 checks.

**Open question for the user:** html2pdf rasterises, so the PDF text is not selectable or
searchable and weighs ~600KB for a 2-minute article. `window.print()` would fix all three.
CLAUDE.md specifies html2pdf.js, so that is what shipped.

Built store packaging — see [[store-packaging]]. `npm run package` validates dist/ against
the store's rules before zipping. Audit found `scripting` declared but never called, and
`<all_urls>` wider than needed: both trimmed, smoke still 84/84. Also generates the five
1280x800 listing screenshots from the real extension.

Every item on the CLAUDE.md feature list is now built and verified in Chrome.

**Closed the open questions** rather than leaving them for the user:
- Added a print path so a PDF can have real, selectable text — 61KB with fonts vs 615KB
  as a flat image, measured on the same article. Both paths ship; see [[pdf-export]].
- `minimum_chrome_version` is no longer a guess: `build.target` compiles to chrome116 and
  `npm run package` fails if the two disagree.
- Wrote `PRIVACY.md`, drafted the listing copy, and generated the 440x280 promo tile, so
  only publishing the policy URL is left to a person — see [[store-packaging]].
Smoke test now 94 checks.
